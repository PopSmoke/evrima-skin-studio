# Evrima Skin Studio

[Download the latest release](https://github.com/PopSmoke/evrima-skin-studio/releases/latest)

Evrima Skin Studio

Private release repository for Evrima Skin Studio by Pops (_bruce. on Discord).
Development assistance: OpenAI Codex (AI).

Latest version: 1.4.1 — Idle Edition

Download Evrima-Skin-Studio-Idle-1.4.1.zip from this repository's Releases page.
Extract the entire ZIP to a normal folder, then run Open Skin Studio.cmd.
Keep its console window open while using Skin Studio.

Included
- All 29 supported dinosaur models and one adult idle animation per species.
- 98 pattern/texture choices.
- Skin JSON import/export, raw numeric color editing and color experiments.
- Corrected Austro, Hypsi and Ovi feather materials and transparency.
- Corrected Psitta painted textures and bristles.
- A visible launcher with startup/error reporting.

Package size: 845,316,998 bytes (about 845 MB).
Extracted files: 992,360,588 bytes (about 992 MB).
Textures retain their source dimensions and decoded pixels through lossless storage.
The ZIP includes the application code, bundled runtime and required assets.

Preview limits
Lighting is an approximation. Bright/extreme colors do not establish native
emission. Psitta's painted body material does not support modern body-color
editing. Some texture choices are asset previews, not verified in-game patterns.

The repository and its release are private. This is the packaged Skin Studio
release; it does not include the separate replay viewer's expanded clip browser.
